# Power-Supply PCB Design Workshop

A responsive event site and enrollment flow for a hands-on PCB design workshop powered by KiCad EDA.

[View the live site](https://design-your-own-power-supply-pcb.vercel.app)

## What it includes

- Workshop overview, curriculum, schedule, and pricing
- Responsive technical brochure design
- Enrollment form with experience and motivation fields
- Payment-proof upload workflow
- Google Apps Script submission backend
- WhatsApp community and KiCad resource links

## Stack

`HTML` · `CSS` · `JavaScript` · `Google Apps Script` · `Vercel`

## Run locally

Open `pcb_workshop_brochure.html` in a browser. The production route is configured in `vercel.json`.
